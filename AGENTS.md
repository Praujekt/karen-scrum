# Interface Naming

Use Title Case consistently for navigation items, page and section headings, metric/card titles, buttons, tabs, field labels, and other structural UI labels. For example: "All Cases", "Coming Up", "Activity Template", "Your Cases", and "Cases Due Soon". Keep short articles, conjunctions, and prepositions such as "a", "and", "the", "of", "to", and "for" lowercase unless they begin the label. Capitalize both main words in hyphenated labels, such as "In-Progress".

Keep explanatory prose in sentence case. Preserve patient names, case notes, document names, and patient-specific activity text as entered.

The product name is **Karen’s Load**. Do not add new Weekwise branding or obsolete launchers. Existing persistent identifiers, historical backup compatibility, and encryption formats must be migrated deliberately if changed; never reset or orphan stored cases as part of a cosmetic rename.
